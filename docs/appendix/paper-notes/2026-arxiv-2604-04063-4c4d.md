## 1. 一句话总结
4C4D 在 4DGS 框架上 plug-in 一个 **Neural Decaying Function (NDF)**：用轻量 MLP 根据 Gaussian 的 center/opacity/rotation 预测一个 per-Gaussian 衰减因子 τ，自适应地调制 opacity，从而在稀疏视角 (4 cameras) 下把 4DGS 偏向 appearance 的优化梯度重新分配到 geometry 上，缓解几何-外观建模的不平衡。

## 2. 摘要 (核心 3 段)

**问题**: 现有 4D Gaussian Splatting (4DGS) 依赖密集相机阵列（数十~数百视角）才能稳定重建。在稀疏视角 (4 cameras) 下，4DGS 优化出现**偏向 appearance 的梯度失衡** — appearance 因容易拟合而过拟合，geometry 因空间监督不足而学得差，进而导致 noised geometry、drifting primitives、unseen view 泛化失败。Plain 4DGS 在 4-camera 设定下 PSNR 只有 20.60 (Neural3DV)，远低于 dense-view 表现。

**方法**: 提出 **Neural Decaying Function (NDF)** f_θ — 一个轻量神经网络，输入每个 4D Gaussian 的 center (x,y,z)、opacity o、rotation r，预测一个 per-Gaussian 衰减因子 τ，将原始的 4DGS 时序 opacity 公式 `o(t) = ω(t)·o` 改造为 `o(t) = τ·ω(t)·o`。τ 的作用是 **neurally modulate opacity** → 重新分配 opacity 的 gradient，使 gradient 更聚焦于 geometric learning。进一步设计 **visibility detection** (spatial Z_V + temporal Z_T) 区分 visible vs. invisible Gaussians：visible 区域用 NDF 预测的 τ，invisible 区域用固定常数 β=0.999 (与 [11] Binocular-guided 3DGS 一致)。

**结果**: 在 Neural3DV (4 cameras from 18-21) 上: 4DGS 20.60→4C4D **22.29 PSNR** (+1.69 dB), LPIPS 0.244→0.146 (−40%); ENeRF-Outdoor: 4DGS 23.52→**24.32 PSNR** (+0.80 dB), LPIPS 0.151→0.121 (−20%); Mobile-Stage: 4DGS 22.15→**22.36 PSNR** (+0.21 dB), LPIPS 0.180→0.121 (−33%); 自采 Dyn4Cam (4 GoPro, <$1500 USD 捕获) 仅做定性对比，无 held-out 量化数据。Neu3D 自报 6 场景，ENeRF 3 场景，Mobile-Stage 1 场景。所有对比均在 4-camera 稀疏训练 / 其余相机作 test 的统一 split 下进行。

## 3. 派系分类
- **A (4DGS representation)**: 主。4C4D 是 4DGS 表示层改进 (per-Gaussian neural opacity decay → 改善稀疏视角下的 geometry 学习)，且作者明确提出 4C4D 适用于 "dense cameras" → "as few as four cameras" 的极端稀疏场景。
- 相关: B (training acceleration) 沾边 — NDF 是个轻量 MLP，整体方法强调 plug-in to existing 4DGS pipeline 不做大幅改造。
- 不属于 C (3DGS 加速，静态) — 4C4D 是 4D dynamic。
- 不属于 D (mobile) — 作者明确说明 4 cameras 是 "mobile phones or portable cameras such as GoPros" 的捕获端，但渲染侧无 mobile/edge GPU 评测。
- E (cross-disciplinary) 沾边有限: Neural Decaying Function 是借鉴 learnable decay / transformer 中的 gating 思想，但未跨 NLP/CV 大类。

**结论**: 主派系 **A**。

## 4. 方法

### 4.1 整体架构 (plug-in to 4DGS)
4C4D 以 4DGS 为 baseline。**核心数学改造只发生在 opacity 公式**：

**Original 4DGS** (Yang 2023 [47]):
- `o(t) = ω(t) · o`, where `ω(t) = exp(−½ (t−μ_t)² / Σ_{4,4})`

**4C4D** (本工作):
- `o(t) = τ · ω(t) · o`, where `τ = f_θ(x, y, z, o, r)`

`τ` 不是优化参数，而是由一个轻量 MLP 持续地根据 Gaussian 当前属性**即时预测**。这与直接把 `o` 改为 learnable 参数 (3DGS 原方案) 的思路相反 — 是用 secondary network 给 opacity "打补丁"。

`f_θ` 实现:lightweight neural network，输入 5 维 (x,y,z,o,r)，输出 1 维 `τ`。作者称其 "simple"，但未给出层数 / hidden dim / 参数量。

### 4.2 Neural Decaying Function (NDF)

**核心观察**: 4DGS 在稀疏视角下 overfit appearance、underfit geometry。
- 4DGS 公式中，opacity o 直接被 photo loss 通过 splatting 路径优化 → 容易把"几何信息"塞进 opacity 调整 (overfit)
- position σ 的 gradient 受多视角约束弱 → 学不到

**NDF 思路**: 让 opacity 不再被直接优化，而是由 secondary network 把"几何线索" (position, rotation) 编码进去再 modulation。原 gradient 仍会通过 splatting 路径回传，但 gradient 路径被 `τ` 重新加权 → 减弱对 appearance 的过度依赖，强化对 geometry 的响应。

具体地，position σ 仍走原始 4DGS 的 deformation 路径 (`σ(t) = σ + X_{1:3,4} · X^{−1}_{4,4} · (t−μ_t)`)，opacity 改成 `τ · ω(t) · o`，其中 `τ = f_θ(σ, o, r)`。

### 4.3 Visibility-Aware Separate Decay Strategy

**问题**: 把 NDF 应用到所有 4D Gaussians (visible + invisible) 会导致优化路径扭曲。

**Solution**: 引入 visibility detection:
- `Z_V(v, σ)`: view intersection — 过滤掉当前 view 中 Gaussian center 不可见的
- `Z_T(t, s_t)`: time intersection — 过滤掉 Gaussian duration 不包含 t 的
- `G_m = Z_V(v, σ) ∩ Z_T(t, s_t, G)`: 当前 view-time 的 visible Gaussians
- `G*_m = G − G_m`: 其余 (invisible)

**Final decay**:
```
τ(g) = f_θ(x, y, z, o, r)   if g ∈ G_m
       β (=0.999)            if g ∈ G*_m
```

Invisible Gaussians 用固定常数 β=0.999 — 引自 [11] Han 2024 Binocular-guided 3DGS 实践，作为稳定性约束。

### 4.4 训练设置
- 4-camera 训练，其余相机作 test
- 300 frames (Neural3DV / Dyn4Cam) 或全序列 (ENeRF / Mobile-Stage)
- 图像下采样 ×0.5 (Neural3DV 2704×2028 → 1352×1014)
- Adam optimizer
- 60 FPS 原帧率，1920×1080 (ENeRF-Outdoor / Mobile-Stage)
- 4 张 portable GoPro 即可构成完整 capture system (Dyn4Cam，<1500 USD)

## 5. 实验

### 5.1 数据集
- **Neural3DV** [Li 2022, CVPR]: 6 动态场景，每个 18-21 相机，2704×2028 @ 30 FPS。前 300 帧。Sparse split: 选 4 个最远位置相机训练，其余测试。
- **ENeRF-Outdoor** [Lin 2022, SIGGRAPH Asia]: 3 户外动态场景，18-camera 阵列，1920×1080 @ 60 FPS。同 4-camera split 策略。
- **Mobile-Stage** [4K4D, Xu CVPR 2024]: 1 复杂多人舞场景，24 相机，1920×1080。稀疏训练选 4 个高 overlap 视角。
- **Dyn4Cam** (self-captured): 4 个 GoPro-style 消费相机，60 FPS，1920×1080，300 frames/scene。**无 held-out 视图**，仅定性。

### 5.2 基线
- **4DGaussians** [Wu CVPR 2024, ref 44]: plane-feature deformation
- **ST-GS** [Li CVPR 2024, ref 20]: hybrid time-aware GS + neural appearance decoding
- **4DGS** [Yang 2023, ref 47]: 原论文 baseline
- **Ex4DGS** [Lee NeurIPS 2024, ref 17]: fully explicit dynamics

### 5.3 评测指标
- **PSNR↑**: pixel-wise ℓ2
- **DSSIM1↓ / DSSIM2↓**: structural dissimilarity，data-range 分别为 1.0 / 2.0
- **LPIPS↓**: perceptual similarity

作者未在主表中报 FPS / training time / number of Gaussians — 不同于我们关心的移动端四项核心指标。

## 7. 评估

**亮点**:
- **Plug-in 设计哲学**: NDF + visibility detection 都是 in-place modification，不改 4DGS 的 deformation/spherical harmonics 路径
- **问题新颖**: 通用 4DGS 工作大多假设 dense cameras (18-21+)，4C4D 显式针对 4-camera 极端稀疏
- **捕获端大众化**: Dyn4Cam 用 4 个 GoPro + <1500 USD，是 paper 上 residential budget 最低的 4D capture system
- **Self-captured dataset**: 提供 Dyn4Cam (虽然做得薄，仅 4 cameras / 无 held-out)，给社区后续 baseline
- **Ablation 充分**: 两个维度 (component + decay variant) 5 个变体
- **Sparse-camera 场景下的 NDF 衰减结构稳健**: ablation 表明 Constant + Vis Detect 也能 work，但 NDF 持续最优

**短板**:
- **没标 FPS / 训练时间 / Gaussian count** — 与本项目其他 4DGS paper notes 风格不一致，无法直接对比效率
- **vs. dense-camera 4DGS**: 完全未比较 — 4C4D 是否在 dense-camera 设定下还 work，未知 (可能 NDF 在 dense 视角下会引入 over-regularization)
- **Mobile port 零数据**: 即使 Dyn4Cam 是 mobile capture，渲染端未在 mobile GPU 上 benchmark
- **未声明 NDF MLP 架构** (层数 / hidden dim / params)，无法做 GPU 算力估算
- **Visible/Invisible 区分依赖 splatting 内部计数器**，不是新东西 — 复用 4DGS 现有 visibility check
- **β=0.999 直接引自 [11]** — 不是本文 novelty，且未做 sensitivity sweep
- **Dyn4Cam 缺定量** — 只能看图，无法验证方法在真"4-camera"环境下的精度上限
- **Number of cameras 全是 4** — 没做 2 / 3 / 6 cameras 的 sensitivity sweep，无法判断 threshold

**对我们的相关性**:
- **中等偏低**。属于 4DGS 表示的**稀疏视角稳定性**改进，而非我们的核心目标 (mobile 实时渲染)
- NDF 的 opacity modulation 思路可借鉴 — 但 paper 没量 GPU 算力开销，无法判断 edge GPU (Adreno) 能否扛
- **不是 mobile-first 工作**: 4 cameras 是 capture 端约束，不是 rendering 端约束
- 如要在 mobile 部署 4C4D，需自评 NDF MLP 的 per-frame forward 开销

## 9. Insight

**Insight #1 — Plug-in 设计哲学延续 4DGS 改造传统**。4C4D 没替换 4DGS 的 deformation / SH 路径，仅在 opacity 公式中插入 `τ = f_θ(·)`。这种 modular enhancement 风格与 MVFusion-GS / ST-GS 一脉相承。我们的 mobile port 设计也应避免从零写 deformation pipeline，优先在 plug-in 层面做减法 (删不必要模块) 和加法 (加 NDF 类似轻量 gating)。

**Insight #2 — 稀疏视角是 4DGS 的真正软肋**。Dense-camera 4DGS 论文主表一般报 30+ PSNR，4C4D 在 4-camera 设定下仅 22.29 PSNR (Neural3DV) — 数量级差距说明 4DGS 对几何监督的数量非常敏感。Mobile 部署时若训练数据来自稀疏 camera (典型场景)，NDF 类 geometry 增强几乎成为必需。

**Insight #3 — Opacity 是 4DGS 几何-外观的"调度旋钮"**。4C4D 把 opacity 的 gradient 重新分配到 geometry，本质上是让"如何用 opacity"成为可学习策略。我们可以思考: 在移动端 GPU 上，opacity modulation 的额外 MLP forward 是否比加 1 个 deformation 网络轻？若 NDF MLP < 1k params，可能比省一组 deformation-feature plane 更划算。

**Insight #4 — Self-captured dataset 是工程参考而非评测**。Dyn4Cam 缺 held-out 视图，所以 paper 只能定性对比。这意味着即使我们 re-capture 一个 4-camera dataset (mobile 端 friendly)，也要**自建 held-out view**或**留 1 相机做 test**，否则 4C4D-style 评测缺数字感。

**Insight #5 — Capture-side 4 cameras ≠ Render-side 4 个视角**。4C4D 的 4 cameras 是 capture 端约束；rendering 阶段仍可在任意 dense NPR trajectory 上生成。Mobile 端我们可以做成"4-camera 训练 + mobile 上 dense trajectory rendering"，这是 4C4D 没明示但天然兼容的部署模式。
