\caption{FPS vs storage scatter plot for mobile / edge-GPU 4DGS
deployments. The 60 FPS red-line is the survey's sustained target;
the 144 FPS line is the panel-recommended minimum for VR-with-motion-
to-photon < 7 ms. ``x'' coordinates are paper-reported per-Gaussian
storage; points tagged ``[storage?]'' sit at x=0 because the paper
did not report per-Gaussian storage (streaming / object-centric /
multi-GB maps). Flux-GS and Mobile-GS cluster at the FPS target;
GS-NFS decodes on a Jetson edge GPU but doesn't sustain 60 FPS;
GaussLite runs at 4 Hz mapping-loop rate (different KPI). Hardware
labels here use Snapdragon 8 Elite / Adreno 830 (Qualcomm's
official naming post-2024), consistent with \S6.3.}
